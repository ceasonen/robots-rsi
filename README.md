## 最新闭合结果

v40比较普通 BC 的保留状态支持：共同 parent、相同 teacher 池、相同可训练参数及每臂2000步更新。`oldA_KL`保留A128；`coverage_KL`用A64加四条既有source轨迹各16状态。两臂保留项均为对parent的joint KL。它是普通固定基线的资格诊断，**不是M/新改进器/RSI**。

| 520步完整任务成功 | parent | oldA_KL | coverage_KL |
|---|---:|---:|---:|
| 原A八条件 | 8/8 | 6/8 | 7/8 |
| source四条件 | 4/4 | 3/4 | 4/4 |
| Long四条件 | 0/4 | 0/4 | 0/4 |

相对同条件parent：oldA为 **0修复、3伤害**，coverage为 **0修复、1伤害**。Long同轨迹延至900步，仅oldA有一次第 **720** 步晚成功，不能替代520主端点。旧A/source没有900步观察，值为`null`。

覆盖约束减少了本次观察到的两次损害，但仍损害A67，也没有产生Long520新能力。source4/4保留的是parent已有成功。两臂同时改变任务与行为状态支持，coverage还减少旧A支持，不能说是纯任务覆盖的单因素因果结论。只有一个训练种子，涉及已知任务新初态，未认证预训练未见。

## 下一步如何验证创新

优先审查**老师真实前缀与自身前缀之后的后缀可恢复性诊断**，保持学生冻结，判断是否具备接续完成任务的能力。目前仅是未注册提案，未启动。老师前缀也占实际动作与绝对任务时钟，不能赠送额外后缀预算。

若连老师前缀后也不能完成，先放下当前学生/老师组合的可用性假设；若只有老师前缀后能完成，才核可靠恢复标签并做标准闭环数据强基线。两路径同时改变状态和历史，不能声称只隔离了分布漂移。

有了可用基线和具体机制后，明确过去反馈改变了哪项“生成下一次新修复”的决定，再在另行冻结条件下比较真反馈、冻结/打乱反馈、强固定BC和普通RL，匹配数据/标签权限、候选、更新及实际采集成本，报告旧能力伤害。没有可重复前瞻净收益就撤下机制主张。一般反馈、三臂对照或改名字不是创新；递归还需独立R1/R2因果证据。
