# 机器人自改进研究：问题、证据、差异化路线（2026-11-04）

> 供导师讨论的研究定位，不是已验证的方法贡献。与 `main` 的历史审计快照分离保存；本分支只追加研究规划，不改写历史实验结果。

## 研究目标（一句话）

机器人执行长时序操作失败后，能否在**可控旧能力损害和真实交互成本**下，主动产生可供学生学习的局部恢复示范，使学生下一次在**新的初态、无教师介入**时独立完成任务？

- **任务类别**：robot manipulation / continual policy learning / failure-driven policy improvement；当前并非 world model 或纯硬件系统。
- **区分三个量**：教师执行成功（assisted success），冻结学生接手成功（handoff success），学生训练后无教师独立成功（autonomous acquisition）。只有第三项可用于主张新能力。
- **修复与损害**：在相同测试条件上报告相对冻结 parent 的 repair（parent 败、student 胜）与 harm（parent 胜、student 败），来源任务与新任务分列；不同评估集不做后验加权净收益。
- **自改进边界**：过去的学习结果必须改变**下一轮产生怎样的新示范**，且在未参与选择的任务上提高新生成策略的独立表现。简单多轮训练、选择固定候选或降低 NLL 不足以声称递归自改进。

## 现有工作已经覆盖什么（防止撞车）

| 方向/论文 | 已做的事情 | 不能当本项目新颖点 |
|---|---|---|
| [LRS](https://arxiv.org/abs/2610.05151) | 从失败状态生成局部恢复；学生接手不成功则延长教师示范 | “根据学生接手判断示范够不够长” |
| [CUPID](https://proceedings.mlr.press/v305/agia25a.html) | 用策略闭环表现估计训练示范价值并筛选数据 | “挑有用示范” |
| [EmbodiRSI](https://arxiv.org/abs/2609.38905) | 从策略失败状态纠错，并面向弱点自适应采集 | “从失败收纠错数据” |
| [AdaRSI](https://arxiv.org/abs/2610.20474) | 先归因子步骤，再按需局部微调 | “只改失败子步骤” |
| [Recursia](https://arxiv.org/abs/2610.24464) | 修复共享执行栈、技能合约与 handoff | “修复阶段衔接” |
| [RESCUE](https://arxiv.org/abs/2610.13516) | 反事实比较继续、干预与停止，研究何时介入值得 | “同一状态下比较干预” |
| [PBYM](https://arxiv.org/abs/2610.13991) | 学习修改效果预测并用结果修订后续修改 | “过去修改反馈改善下一轮改法” |
| [PRACTICE](https://arxiv.org/abs/2608.30760) | 从经验学习技能库的增删改合并 | “反思后维护技能库” |

**差异化假设（尚未实现）**：在**同一真实失败前缀**上生成多种**教师都可执行成功**的物理纠错，但不同纠错的**学生可学性**不同；让系统依据该学生过去的训练后闭环收益，主动改变**下一批纠错的动作序列、交接状态或时长**，而非只选择/排序现有数据。目标是学生从新初态独立恢复，并对旧能力损害施加约束。

此方向与 LRS 的交接长度、CUPID 的数据筛选、RESCUE 的干预效用和 AdaRSI 的局部微调均有交集；只有证明“**主动合成的教师干预在不同学生之间存在可预测的教学价值差异，反馈改善下一轮生成**”，才可能构成可辩护的独特机制。先做完整文献对照，不能预称填补空白。

## 建议的科学路线

1. **先验证接续能力**：按已有 root verdict 中的 24 回合提案（4 个老师上下文×3 actor×自身前缀/严格教师前缀），在完整物理/控制器/策略历史重放下比较从相同绝对时钟接手的后缀成功。该提案目前未注册、未执行，不能把“老师能做”写成“学生有可修复接续能力”。
2. **隔离物理与策略历史**：在同一实际物理前缀上改变可实现的历史处理，与等时物理退让对照分开测。物理路径不同会改变后续观测，不把它冒充“纯物理因果效应”。
3. **同失败状态的多教师干预**：预先筛选两种都能在教师侧成功的纠错方式，再以相同 teacher 控制步/标签/学生更新/验证总成本训练 student，测独立迁移与 harm。不同 student 上的教法排序反转是强证伪/支持信号。
4. **反馈改变生成过程**：使用开发集的学生学习进展预测新一轮生成哪类示范，比较最优固定教法、随机教法、真反馈、打乱反馈、普通 BC/RL 与预算匹配版本。在新任务和新 parent 上测独立成功，而非复用挑参数集。
5. **只有有正信号才扩展**到更多 LIBERO task clusters 和多随机种子；再考虑物理实机复现。

## 会议中需导师决策

- 优先确认具体的可恢复失败任务族（接力抓取 / 重抓 / 二阶段放置）与公开可复现平台；避免试图解释 Long90 所有失败。
- 对比对象至少包括 LRS 式局部监督、强固定 BC、无需学习的 backtrack/retreat、固定 teacher 与假反馈。
- 若 24 个老师前缀测试中学生仍全部失败，则先换具备原子技能的 parent/任务，不应直接花预算训练更复杂的 meta-improver。
